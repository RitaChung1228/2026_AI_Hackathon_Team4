## 1. 執行摘要與產品願景 (Executive Summary & Vision)

UNI Flow 是一款基於生成式AI核心的智慧社區與零售服務管家。傳統零售與社區APP往往停留在「使用者主動搜尋 → 比較商品/服務 → 填寫表單/下單」的繁瑣線性流程。UNI Flow 翻轉此模式，提出「**三層式動態對話與情境服務架構**」，以AI自動化理解使用者情境、預測需求，並一站式完成「食衣住行育樂」的服務整合與商品打包下單。

> **核心產品願景 (Core Vision)**
>
> 成為每一位用戶與家庭的「智慧生活雙腦」，透過懂生活的AI，將複雜的生活瑣事化繁為簡，結合統一集團無縫生態圈，實現「隨口一句，全家搞定」。

## 3. 核心產品架構：三層式動態模型 (3-Layer Architecture)

UNI Flow 將「情境包」定義為彈性工具組（Preset Toolkits），而非固定流程，由三層架構運作：

### 第一層：使用者 Profile (User Profile Layer)

**定位**：用戶長期記憶與個性化偏好引擎。

- **機制**：整合上述Hashtag標籤，決定AI推薦邏輯（如：優先推薦快速門市取貨 vs 優先推薦最低折扣組合）。

### 第二層：情境包 (Scenario Package Layer)

**定位**：預設多任務打包與常用行程範本（Bundle Packages）。

- **機制**：將常見場景所需的「微任務 + 跨業態服務 + 門市商品」打包為預設模組，支援用戶一鍵套用或開啟對話修改。

### 第三層：臨時任務 (Ad-hoc Task Layer)

**定位**：即時、單次、極具個性化的非標準需求。

- **機制**：完全不需套用既有情境包，Semantic Agent 直接 Parsing 自然語言輸入（如「今天下班幫我買個生日蛋糕」），AI自動建立獨立Task。

## 5. 功能規格與產品交互流程 (Functional Specifications & Workflows)

### 5.1 行程包管理與自訂 (Bundle Lifecycle Management)

- **開啟對話生成新行程包**：用戶可選擇既有行程包或直接在Semantic Agent對話框輸入需求（如「下週三要去東京出差」），AI即時Parsing並生成新行程包。
- **儲存常用行程包**：自訂或修改後之行程包可一鍵點擊「儲存為自訂行程包」，存放於UI之「我的情境包」專區，供日後重複調用。
- **AI步驟拆解與進度追蹤**：點選任意行程包，AI將任務拆解為細部步驟（Step-by-Step Task List），並以進度條（如：已完成60%）即時呈現。

### 5.2 環境與天氣感知推薦 (Context & Weather Engine)

**觸發邏輯**：整合Weather API與LBS位置。氣溫驟降（< 16°C）主動推薦保暖衣物與火鍋預訂；降雨機率高（> 70%）自動將雨具採購與yoxi叫車加入清單。

### 5.3 行程共享與社群抽卡 (Social & Shared Hub)

- **行程共享**：預約完成之行程包可一鍵分享給LINE好友或同步至Google/Apple Calendar。
- **午夜社群抽卡**：每日24:00根據Profile標籤與近期行程，隨機抽卡配對生活型態相似之用戶，匿名瀏覽並一鍵複製對方的優質行程包。

## 6. 系統資料庫與大會 API 對接架構 (Technical Architecture)

UNI Flow 後端與競賽提供之 PostgreSQL / JSONB 資料結構完整對接：

| 系統功能 | 對接資料表 (Database Tables) | 關鍵欄位與技術實現 |
|---|---|---|
| 服務商與項目檢索 | `cms_homepage_service_vendor`<br>`cms_homepage_service` | 按服務類型type分類匹配（1:清潔, 2:家電清洗, 3:寄件, 6:訂位, 9:外送, 11:購物） |
| 複雜服務問答預約 | `pms_form`<br>`pms_form_topic`<br>`pms_form_feedback` | 清潔/家務等服務調用動態問答表單，個資欄位採AES-256-GCM加密儲存 |
| 打包交易與訂單統一 | `mms_order_record` | `inbr_account_id`: UUID v7會員代碼<br>`vendor_data`: JSONB儲存服務商特有參數<br>`order_items`: JSONB儲存多重商品與服務明細<br>`order_type`: 01服務 / 02訂位 / 05商品 |
